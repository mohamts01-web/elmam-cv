# تحرير الورقة ومراجعة الاستيراد

نُشرت الإضافة في مشروع Netlify الحالي `etmam-cv` بالتحديث `6ae586bf5b505273246e6241`. أُكملت مراجعة النسخة المنشورة في 1 نوفمبر 2026.

## الوظائف المنفذة

- تحرير النصوص مباشرة داخل الورقة، مع تحديد الكلمات للغامق والمائل والتسطير والروابط. التنسيق محفوظ كنطاقات نصية آمنة مرتبطة بالنص نفسه؛ لا يُخزّن HTML حر من المتصفح.
- أدوات للقسم تشمل الترتيب والإخفاء والإظهار والحذف وحجم النص والقائمة النقطية. نسخ العناصر وتحريكها وحذفها يحترم مستوى العنصر: نقطة مسؤولية تبقى نقطة داخل الخبرة نفسها.
- الدورات: اسم الدورة، الجهة المانحة، تاريخ مرن، ووصف اختياري. يمكن فتح الحقول من القسم أو لوحة المحتوى، وتظهر التفاصيل في الورقة والتصدير. تبقى بيانات الدورات بصيغة النص المتوافقة مع البوت، دون إسقاط المعلومات القديمة.
- الاستيراد يعيد المحتوى مع ملخص ومقترحات مراجعة في الطلب نفسه. لا يضيف بيانات غير مقدمة. تظهر أعداد الأقسام المستخرجة، ويستطيع العميل مراجعة المحتوى قبل اعتماده.
- نافذة المقارنة تدعم اعتماد قسم واحد أو الأقسام المتبقية كلها. يبقى الطلب مرتبطًا بإصدار المسودة، وتُرفض الاقتراحات القديمة بعد تعديلها. الاعتماد الجزئي أو إعادة المحاولة لا يخصمان عملية جديدة.
- يشارك الموقع والبوت محرك PDF نفسه؛ أُبطل التخزين المؤقت للنسخ ذات المحرك القديم بإصدار جديد.

## النشر والتحقق

- ترحيل `20261031055723_etmam_selective_cv_proposals.sql` مطبق. وظائف API/Telegram/Maintenance نشطة بالإصدارات 5/6/7 عند هذا النشر.
- حُدّث `etmam-cv-renderer` فقط؛ احتُفظ بالأسرار والربط وجدول الاستعادة كل خمس دقائق. لم تتغير خدمة نشر الوظائف.
- نجحت اختبارات الوحدة الـ23، وفحص TypeScript وبناء الواجهة وفحص Deno للوظائف الثلاث.
- نجح اختبار SQL للاعتماد الجزئي، وتكرار الاعتماد، ومنع الاقتراح القديم دون زيادة الاستهلاك. ونجح الاختبار السحابي المعزول من 11 حالة، بما فيها استيراد فعلي وتحسين وترجمة وتصدير وحذف بيانات الاختبار.
- أُعيد توليد ملفات القوالب الثلاثة بالعربية والإنجليزية، مع محتوى طويل متعدد الصفحات، وفُحص قياس A4 والنص القابل للتحديد.
- اختُبر إدخال النص وتنسيقه ونسخ نقطة خبرة وحقول الدورة الأربعة في المتصفح ببيانات تجريبية. فُحص تنقل الهاتف بإطار 390×844 دون امتداد أفقي للصفحة، ثم أُعيد إطار العرض إلى وضعه الافتراضي. هذه محاكاة هاتف وليست اختبار جهاز فعلي.

صورة مراجعة النسخة المنشورة: `docs/screenshots/inline-courses-final.png`.

## حدود واضحة

الواجهة مستوحاة من نمط تحرير الأقسام، وليست نسخة مطابقة لكل أدوات أسطر. الإضافة من شريط الورقة تفتح الحقول المنظمة للقسم. تعرض اقتراحات المراجعة خطوات تالية؛ التحسين الذي يستدعي النموذج يتطلب عملية ناجحة مستقلة موضحة للمستخدم. تبقى الباقة مسودتين و8 عمليات خلال ثلاثة أشهر.
